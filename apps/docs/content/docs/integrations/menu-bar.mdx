> **DEPRECATED — PROJECT ARCHIVED.** This page documents a historical integration. The the-brain menu bar app is no longer maintained or supported.

## Historical Installation

The former macOS installer built the menu bar app and configured its LaunchAgent. New installations are not supported.

## Historical Features

The historical app provided:

- **Status indicator**: Green dot = daemon running, gray = stopped
- **Memory counts**: Instant / Selection / Deep layers
- **Quick actions**: Consolidate, Train, Wiki Generate
- **Drag & drop**: Drop files onto the menu bar icon to ingest them
- **Remote mode**: Read `THE_BRAIN_REMOTE_URL` and `THE_BRAIN_AUTH_TOKEN` from the environment

## Historical LaunchAgent

The menu bar app started automatically on login via `~/Library/LaunchAgents/com.thebrain.bar.plist`.

The daemon also auto-started via `~/Library/LaunchAgents/com.thebrain.daemon.plist`.

```bash
the-brain daemon enable   # Enable auto-launch
the-brain daemon disable  # Disable auto-launch
```

## Historical Source Build

```bash
cd apps/menu-bar
swift build
open .
```

## Troubleshooting

### "missing required module 'SwiftShims'"

If you renamed or moved the project directory, Swift's precompiled module cache retains stale paths:

```bash
cd apps/menu-bar
swift package clean
swift build -c release
```

# the-brain archive

**the-brain is a deprecated project archive.** This documentation preserves the former 3-layer cognitive architecture and extension-first design for reference.

> **DEPRECATED — PROJECT ARCHIVED.** the-brain is no longer maintained. Do not install or use it for new projects. Source code and documentation are preserved for reference only.

## What the-brain Was

AI tools forget between sessions. the-brain was designed to remember across the tools you used. It harvested conversations, filtered noise from signal, and consolidated what mattered. No cloud. No telemetry. Just a background daemon learning your patterns.

## Architecture at a Glance

The former architecture fed AI tools into three plugin slots:

```
Any AI tool → ⚡ INSTANT slot — immediate context (default: graph-memory)
            → ⚖️ SELECTION slot — retained information (default: spm-curator)
            → 🌌 DEEP slot — long-term consolidation (default: mlx-lora + auto-wiki)
```

Each slot was replaceable. The daemon loaded configured extension names from `config.json` (`"extensions": ["my-ext"]`); extensions were **disabled by default** for security.

## What the-brain Was Designed to Learn

- **Corrections** — "No, actually use `useCallback` here" → remembered for later
- **Preferences** — "I prefer arrow functions" → injected into later contexts
- **Patterns** — Repeated choices across sessions → suggested related concepts
- **Identity** — Stable preferences and style tracked across retrains

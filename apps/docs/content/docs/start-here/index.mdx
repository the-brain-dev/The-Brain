> **DEPRECATED — PROJECT ARCHIVED.** This onboarding section is retained for historical reference. the-brain is no longer maintained and has no supported installation path.

the-brain was an extensible background daemon that observed interactions with AI tools and built a persistent memory tailored to **you**.

## What the-brain Was

AI tools forget between sessions. the-brain was designed to remember patterns, preferences, corrections, and evolving style. It ran locally and required no manual input.

## Historical Onboarding

The installation and quickstart material in this section describes the former project workflow only. Do not use it to start a new installation.

## What the-brain Was Designed to Learn

- **Corrections**: "No, actually use `useCallback` here" → remembered for later
- **Preferences**: "I prefer arrow functions" → injected into later contexts
- **Patterns**: Repeated choices → suggested related concepts
- **Projects**: Per-project memory isolation with cross-project promotion
- **Identity**: A stable self-vector tracked across retrains

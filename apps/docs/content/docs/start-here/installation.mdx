> **DEPRECATED — PROJECT ARCHIVED.** Installation is no longer supported. The public installer has been removed, and this page is retained only to document the former setup.

## Historical Setup

The former installer configured Bun, `uv`, the CLI, the daemon, and the macOS menu bar app. It is not available for new installations.

Existing local checkouts and installations are unsupported and should not be upgraded through this documentation.

## Historical Platform Support

- **macOS**: Bun CLI, menu bar app, and LaunchAgents
- **Linux**: Bun CLI and remote mode with an auth token

## Historical Configuration

The former setup wizard configured harvesters, memory layers, and optional MLX/LLM backends. Those choices are preserved here as project history, not as a supported workflow.

## Prerequisites

The historical project used [Bun](https://bun.sh), Python 3.11+, and `uv` for optional MLX features. These prerequisites do not constitute a supported installation path.

No supported installation, initialization, remote-mode setup, or verification path remains.
